# Сила — дневник тренировок

Статическое приложение для ведения тренировок по пауэрлифтингу. Работает целиком в браузере и подходит для публикации на GitHub Pages: сервер, регистрация и внешняя база данных не требуются.

## Возможности

- создание, редактирование, удаление и поиск тренировок;
- несколько упражнений с подходами, повторами и весом;
- заметки и ссылки на видео;
- локальный профиль спортсмена;
- адаптивный интерфейс для телефона и компьютера;
- хранение данных в `localStorage` текущего браузера.

## Запуск

Откройте `ver1/index.html` или запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

После этого приложение доступно по адресу `http://localhost:8000/ver1/`.
